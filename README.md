# HyperSU-Docs

The HyperSU's Document Website

[![Pages](https://github.com/HyperSU-Team/HyperSU-Website/actions/workflows/main.yml/badge.svg)](https://github.com/HyperSU-Team/HyperSU-Website/actions/workflows/main.yml)

## Development

### Requirement

 - NodeJS
 - bun
 - Rust Stable (For wasm build)
 - Clang(LLVM) (For wasm build)

### Commands

```shell
bun install

# dev
bun run docs:dev --host

# build
bun run docs:build

# preview
bun run docs:preview
```

## Notes

This Website using `Misans VF` and `JetBrains Mono` fonts.
