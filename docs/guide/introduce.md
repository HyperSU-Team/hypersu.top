# About HyperSU

## What is HyperSU? {#what-is-hypersu}

HyperSU is a kernel-level ROOT solution for Android built on KernelSU. Its upstream is SukiSU, and it focuses on stability and Non-GKI device compatibility.

## Features {#features}

- Kernel-based `su` and root access management
- App Profile: per-app root permissions and mount rules
- Supports Non-GKI and GKI 1.0 kernels; older 4.4+ kernels work with a manually built kernel
- The manager offers theme customization and a built-in SUSFS configuration tool

## Supported architectures {#architectures}

Currently `arm64-v8a`, `armeabi-v7a` and some `x86_64`.
