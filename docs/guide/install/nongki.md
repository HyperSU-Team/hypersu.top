# Non-GKI Devices

This page covers the HyperSU installation process for Non-GKI devices.

::: warning
Non-GKI kernels are highly fragmented and require device-specific integration and compilation. Generic images cannot be used directly.
:::

::: danger
You generally need to find a bootable kernel before you can continue. This may be difficult on devices with incomplete or entirely unavailable source code.
:::

See [Building Kernel](../build) and [Manual Hooks](../manual-integrate) for the integration workflow.
